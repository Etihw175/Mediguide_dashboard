# MediGuide AI — Data Storytelling Dashboard

รายวิชา **Business Idea Creation** · ธุรกิจ: **MediGuide AI** (กลุ่มอุตสาหกรรมยา)
แอป AI แนะนำยาสามัญตามอาการเจ็บป่วยเล็กน้อย พร้อมเภสัชกรรับรองและร้านยาพาร์ทเนอร์

## เปิด Dashboard

ดับเบิลคลิก `dashboard/index.html` (ต้องต่ออินเทอร์เน็ตเพื่อโหลด ECharts + ฟอนต์จาก CDN)
หรือรันเซิร์ฟเวอร์: `python -m http.server 8765 -d dashboard` แล้วเปิด http://localhost:8765

```
mediguide-dashboard/
├── dashboard/
│   ├── index.html          # Dashboard (HTML + ECharts)

│   ├── fetch_raw_data.py        # 1) ดาวน์โหลดข้อมูลจริง
│   ├── etl_build_warehouse.py   # 2) ETL → star schema
│   └── build_dashboard_data.py  # 3) pack เป็น dashboard/data.js

    ├── data_dictionary.md
    └── power_bi_guide.md   # วิธีทำเวอร์ชัน Power BI จาก CSV ชุดเดียวกัน
```

## ข้อจำกัดของข้อมูล

- ทะเบียนไข้หวัดใหญ่เป็นผู้ป่วยที่ **มารับบริการและถูกรายงาน** — ไม่รวมคนที่ซื้อยากินเอง (ซึ่งคือกลุ่มเป้าหมายของ MediGuide) ตัวเลขจริงในชุมชนจึงสูงกว่านี้
- อาชีพ "ไม่ระบุ" ~54% ของผู้ป่วย — กราฟอาชีพใช้ดูสัดส่วนในกลุ่มที่ระบุได้
- "รักษาช้า ≥ 2 วัน" คำนวณจาก `treated_date − onset_date` ตัดค่าที่ < 0 หรือ > 30 วัน
- อัตราการใช้อินเทอร์เน็ตรายภาค = ค่าเฉลี่ยเซลล์ (เขตการปกครอง × เพศ) ที่ สสช. เผยแพร่ ไม่ได้ถ่วงน้ำหนักประชากร
- หน่วยมูลค่าตลาดยาเป็น "ล้านบาท" ตามไฟล์ของ อย.
